# 图标文件说明

## 必需的图标文件

请确保以下图标文件存在：

- Windows: resources/icons/icon.ico (256x256 推荐)
- macOS: resources/icons/icon.icns (512x512 推荐)
- Linux: resources/icons/icon.png (512x512 推荐)

## 图标转换工具

在线工具推荐：
- https://icoconvert.com/
- https://iconifier.net/
- https://cloudconvert.com/
